    How to play

    The lock has five letter dials. Set them to today's secret word in six attempts.

    Type a real word to set the dials, then press Enter. Each dial either locks or tells you which way to turn it. If the code were STACK and you tried CRANE:

    C▼R▼AN▲E▼
    ALocked. That letter is right and stays set, so you can skip it when typing. E▼Turn down. The right letter is later in the alphabet. N▲Turn up. The right letter is earlier in the alphabet.

    Every dial shows the letters it could still be, and the keyboard dims the ones that can't fit the next dial.

    The self-destruct clock gives you three minutes. It starts on your first letter. If it hits zero, the code is lost.

    Everyone gets the same code. A new one arrives every day at 7am UK time.
